# 27. Instalace a odinstalace aplikací v systému Linux

>[!question] Instalace a odinstalace aplikací v systému Linux
>Možnosti instalce aplikací (zdrojové kódy, knihovny, kompilace, instalační balíčky), balíčkovací systém dnf (repozitáře - konfigurace, konfigurační soubory práce s dnf), výhody balíčkovacích systémů; rpm balíčky, řešení závislostí, vlastní příkaz rpm. Instalace ze zdrojových kódů – výhody a nevýhody kompilace - srovnání s balíčkovacím systémem. ( ldd, ./configure, make, makeinstall, gcc ).

## Způsoby instalace

Instalovat aplikace na Fedora Linux můžeme následujícími způsoby

- Z repozitářů
- Ze stažených balíčku
- Kompilací zdrojového kódu

---

### Instalace z repozitářů

>[!info] Repozitář
>Vzdálené uložiště s balíčky

>[!info] Balíček
>Soubor s kódem aplikace

Pro instalaci balíčku z repozitářu nabízy Fedora dva příkazy, `yum` nebo`dnf`

- `dnf` je nástupcem `yum`
- Oba mají stejnou funkčnost, ale `dnf` je rychlejší a má lepší podporu
- `yum` má stále zpětnou podporu
- Společně se zadaným balíčkem se stáhnou i závislé balíčky (většinou knihovny)

Syntaxe `dnf`

```bash
# instalace
dnf install <název balíčku>

# aktualizace všech nainstalovaných balíčku
dnf update

# aktualizace vybraného balíčku
dnf update <název balíčku>

# smazání balíčku (včetně závislostí)
dnf remove <název balíčku>
```

---
### Instalace ze stažených balíčků

Na rozdíl od `dnf` neumí stáhnout závislé balíčky, to závisý na uživateli, který je musí stáhnout a nainstalovat

Syntaxe `rpm`

```bash
# instalace balíčku
rpm -i <název .rpm souboru>

# aktualizace balíčku (musí být velké U)
rpm -U <název .rpm souboru>

# smazání balíčku
rpm -e <název balíčku>

# přeinstalace balíčku
rpm --reinstall <název .rpm souboru>
```

### Kompilace

Step-by-step návod na instalaci pomocí kompilace zdrojového kódu

0. Získej archiv (`.tar`, `.gzip`,...) se zdrojovým kódem
1. Rozbal archiv do normální složky (`unzip`, `tar -xf`,...) a přesuň se do nové složky
2. Přečti si README pro instrukce
3. Spusť `./configure` pro konfiguraci a vytvoření `MAKEFILE`
4. Zkompiluj aplikaci pomocí `make`
5. Instaluj pomocí `make install`

>[!warning] Pozor
>- Pro kompilace je nutné mít nainstalovaný potřebný kompilátor
>- Instalace ze zdrojového kódu nestahuje závislosti
