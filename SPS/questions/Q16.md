# 16. Diskový systém pod operačním systémem Windows Server

> [!question] Diskový systém pod operačním systémem Windows Server
> Základní a dynamické disky, typy svazků dynamických disků – rozdíly a význam, signatura disku, utility pro práci s disky, správce disků – převedení na dynamické disky, konfigurace, souborový systém NTFS, princip ukládání dat (metasoubory, atributy), omezení místa na svazku uživatelům (kvóty) – konfigurace, protokolování a audit kvót.

---

**Základní pojmy:**
- **Oddíl (Partition):** Logicky vymezená část fyzického disku.
- **Svazek (Volume):** Formátovaná oblast disku připravená k použití OS (má přiřazené písmeno nebo cestu).

---

## Základní vs. Dynamické disky

### Základní disk (Basic Disk)
- Tradiční typ disku. Obsahuje primární a rozšířené oddíly.
- Používá tabulku oddílů **MBR** (do 2 TB, max 4 primární oddíly) nebo **GPT** (nad 2 TB, modernější).

>[!pros] Výhody
>- Jednoduchost
>- široká kompatibilita

>[!cons] Nevýhody
>- Omezené možnosti měnit velikost oddílů
>- nepodporuje softwarový RAID přes více disků

### Dynamický disk (Dynamic Disk)
- Umožňuje pokročilou správu svazků nezávisle na klasických oddílech.

>[!pros] Výhody
>- Měnit velikost bez formátování
>- tvorba RAID svazků (0, 1, 5)

>[!cons] Nevýhody
>- Kompatibilní pouze se systémy Windows Server (a vyššími edicemi desktopu)
>- systémový oddíl by měl být na základním disku

---

## Typy svazků na dynamickém disku

- **Jednoduchý svazek (Simple):** Využívá prostor na jednom fyzickém disku.
- **Rozložený svazek (Spanned):** Kombinuje volné místo z více disků do jednoho celku. Data se ukládají postupně.
- **Pruhovaný svazek (Striped - RAID 0):** Rozděluje data rovnoměrně mezi více disků. Zvyšuje výkon, ale nemá redundanci (selhání 1 disku = ztráta všeho).
- **Zrcadlený svazek (Mirrored - RAID 1):** Duplikuje data na dvou discích. Vysoká odolnost proti chybám.
- **RAID 5:** Vyžaduje min. 3 disky. Kombinuje výkon a ochranu dat pomocí paritních informací.

## Správa disků a utility

Pro správu disků se používá grafická konzole **Správa disků** (`diskmgmt.msc`) nebo nástroje příkazového řádku.

**Diskpart (CLI):**
- `list disk` / `list volume` – zobrazení informací.
- `select disk X` – výběr disku pro další operace.
- `create partition primary size=10240` – vytvoření oddílu.
- `extend` / `shrink` – změna velikosti svazku.

## Souborový systém NTFS

NTFS (New Technology File System) je standardem pro Windows Server. Podporuje velké soubory, šifrování, kompresi a podrobné zabezpečení (ACL).

### Princip ukládání dat
Data jsou organizována pomocí **Master File Table ($MFT)**, což je databáze popisující všechny soubory na disku.
- **Metasoubory:** Systémové soubory spravující strukturu disku (např. `$MFT`, `$LogFile`).
- **Atributy:** Každý soubor je definován atributy (název, čas vytvoření, oprávnění, samotná data).

## Diskové kvóty

Kvóty umožňují omezit množství místa na disku, které může konkrétní uživatel využít.
- **Soft limit:** Upozornění uživatele při překročení.
- **Hard limit:** Zákaz dalšího zápisu dat.

![Nastavení diskových kvót](/SPS/imgs/Q16/image113.png)

![Přiřazení kvót uživatelům](/SPS/imgs/Q16/image114.png)

### Protokolování a audit
- **Protokolování:** Záznamy o překročení limitů v Prohlížeči událostí (Systém).
- **Audit:** Sledování, kdo se soubory pracoval (vytvoření, smazání, změna). Nastavuje se v bezpečnostních zásadách a ve vlastnostech složky/disku (Zabezpečení -> Upřesnit -> Auditování).
