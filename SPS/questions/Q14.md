## IIS (Internet Information Services)

- IIS je serverová služba integrovaná do systému Microsoft Windows Server.
- Umožňuje poskytovat webové služby a aplikace přes protokoly **HTTP, HTTPS, FTP, SMTP**.

**Hlavní funkce:**
- Hostování webových stránek a aplikací.
- **FTP server** – pro přenos souborů.
- **HTTPS** – šifrovaná a bezpečná komunikace.
- **Řízení přístupu** – autentizace uživatelů (vazba na lokální účty nebo AD).

## Jednotlivé služby IIS

**Webový server (HTTP/HTTPS)**
- Slouží k publikování webového obsahu. HTTPS vyžaduje SSL certifikát.

**FTP server**
- Používá se pro nahrávání a stahování souborů v síti.

**SMTP**
- IIS může fungovat jako jednoduchý poštovní server pro odesílání e-mailů.

---

## Zabezpečení přenosu (SSL/TLS)

- Slouží k šifrování dat mezi klientem (prohlížečem) a serverem.
- Zabraňuje odposlechu (Man-in-the-middle) a potvrzuje identitu serveru.

**Typy certifikátů:**
- **Self-signed:** Podepsaný sám sebou (zdarma, ale prohlížeč hlásí chybu důvěryhodnosti).
- **CA-signed:** Podepsaný důvěryhodnou certifikační autoritou.
- **Wildcard:** Platí pro doménu i všechny její subdomény (např. `*.domena.cz`).

## Ověřování uživatelů v IIS

**1. Anonymní přístup**
- Uživatelé nemusí zadávat jméno ani heslo. Vhodné pro veřejné weby.

**2. Ověření bez AD (Lokální)**
- Používají se uživatelské účty vytvořené přímo na daném serveru.

![Anonymní ověření](/SPS/imgs/Q14/image82.png)

**3. Ověření s Active Directory (Windows Authentication)**
- Uživatelé se ověřují doménovými údaji.
- Server musí být v doméně. Vhodné pro firemní intranety.

![Windows Authentication](/SPS/imgs/Q14/image87.png)

**4. Ověření pomocí klientského certifikátu**
- Nejvyšší úroveň zabezpečení.
- Server vyžaduje, aby měl klient nainstalovaný platný certifikát vydaný autoritou.
- V nastavení IIS se u webu zapne **Require SSL** a Client certificates se nastaví na **Require**.

![Require SSL](/SPS/imgs/Q14/image91.png)
