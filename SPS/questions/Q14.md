# IIS

> [!example] IIS (Internet Information Services) 
> je serverová služba integrována do sytému Microsoft WS
> umožňuje poskytovat webové služby a aplikace přes HTTP, HTTPS, FTP, SMTP

# Hlavní funkce:

- hostování webových stránek
- hostování webových aplikací
- FTP server
- HTTPS, šifrovaná komunikace
- řízení přístupu k webům (autentizace uživatelů)
- propojení s AD (centrální zpráva a ověřování uživatelů)
