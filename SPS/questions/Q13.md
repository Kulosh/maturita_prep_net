> 
> Dynamické přidělování IP adres – výhody, nevýhody, rozdíl mezi statickým a dynamickým přidělováním IP adres, základní části DHCP služby (DHCP klient, DHCP server, DHCP relay) a jejich konfigurace v prostředí Microsoft Windows s A.D. i bez A.D.; propojení služeb DNS a DHCP v prostředí Microsoft Windows.

---

## Dynamické přidělování IP adres

- slouží k automatickému získávání IP adres pro zařízení v síti.

**Výhody:**
- **Automatizace:** Nemusíme ručně konfigurovat každé zařízení.
- **Efektivita:** IP adresy se uvolňují pro další zařízení (lease time).
- **Minimalizace chyb:** DHCP server nepovolí duplicitní IP adresy.
- **Centrální správa:** Všechna nastavení na jednom místě.

**Nevýhody:**
- **Závislost:** Pokud DHCP server selže, nová zařízení nedostanou adresu.
- **Nevhodné pro servery:** Servery, switche a routery by měly mít statickou IP.

---

## Základní části DHCP služby

**DHCP klient**
- Zařízení, které žádá o IP adresu.
- Komunikuje přes **UDP**.
- **Proces (DORA):**
    1. **Discover** – klient vysílá broadcast požadavek.
    2. **Offer** – server nabídne IP adresu.
    3. **Request** – klient potvrzuje zájem o nabídku.
    4. **Acknowledge** – server potvrdí přidělení adresy.

**DHCP server**
- Spravuje rozsahy IP adres (**Scope**) a přiděluje je.
- Uchovává: IP adresy, rezervace, dobu pronájmu (Lease), bránu, DNS atd.

**DHCP relay agent**
- Slouží k přeposílání požadavků do jiné sítě.
- Pokud je klient v jiné podsíti než server, relay agent (často router) přeposílá DHCP zprávy mezi nimi.

---

## Konfigurace DHCP

**Bez Active Directory:**
- Server funguje samostatně (vhodné pro malé sítě).
- **Postup:** Instalace role DHCP -> Konfigurace rozsahu (Scope) -> Definice Lease time, Gateway, DNS.

**S Active Directory:**
- DHCP server musí být **autorizován** v AD (zajišťuje, že v síti nejsou „nepřátelské“ DHCP servery).
- **Postup:** Instalace role -> Autorizace (Server Manager → DHCP → Authorize) -> Vytvoření Scope.

---

## Propojení DHCP s DNS

- Umožňuje automatickou aktualizaci DNS záznamů (A i PTR) při přidělení nebo uvolnění IP adresy.
- DHCP server může za klienta zaregistrovat jeho jméno v DNS zóně.
