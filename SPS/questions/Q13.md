# Dynamické přidělování IP adres

- slouží k automatickému získávání IP adres pro zařízení v síti

> [!pros] Výhody:
> - automatizace správy IP adres – nemusíme ručně konfigurovat IP adresy
> - efektní využití IP adres – při odpojení zařízení se po čase uvolní IP adresa pro další zařízení
> - minimalizace chyb v nastavení IP adres (třeba při duplikaci stejné IP adresy nám to DHCP nepovolí)
> - centrální správa

> [!cons] Nevýhody:
> - závislost na DHCP serveru – pokud server selže, nelze přidělovat dynamicky IP adresy
> - v DHCP radši nepřidělujeme IP adresy serverům, switchům, routerům

## Základní části DHCP služby:

### DHCP klient
- je to zařízení, které žádá o IP adresu
- komunikuje mezi serverem pomocí UDP
- proces:  
	1. DHCP Discover – klient vysíla broadcast požadavek
	2. DHCP Offer – server nabídne IP adresu
	3. DHCP Request – klient potvrdí, že chce tuto nabídku
	4. DHCP Acknowledge – server potvrdí přidělení IP adresy

### DHCP server
- je zařízení, které spravuje rozsah IP adres a přiděluje je klientům
- uchovává: IP Adresy, Rezervace, Dobu pronájmu, Ostatní možnosti (jako přidělení brány, DNS …)


### DHCP relay agent
- slouží k přidělování adres do jiné sítě
- pokud je klient v jiné síti než DHCP server, relay agent přeposílá DHCP zprávy mezi nimi

# Konfigurace DHCP bez AD

- server funguje samostatně, bez nutnosti autorizace
- vhodné pro malé sítě
- Postup:
	1. přidat roli „DHCP Server“ ve správci serveru
	2. nakonfigurovat rozsah IP adres
	3. definovat lease time, gateway, DNS, WINS
	4. spustit službu a otestovat přidělení IP klientům

# Konfigurace DHCP s AD

- DHCP server může být autorizován v AD, což zajišťuje, že pouze schválené servery přidělují adresy
- Postup:
	1. Instalace role DHCP.
	2. Autorizace v Active Directory (Server Manager → DHCP → Authorize).
	3. Vytvoření scope, nastavení možností (DNS, brána atd.).
	4. Aktivace automatických aktualizací DNS záznamů.

# Propojení DHCP s DNS

- umožňuje propojení s DNS záznamy, a to zajistí automatické aktualizace záznamů
- pokud klient uvolní IP adresu , DHCP může odstranit příslušný DNS záznam, aby se předešlo starým neplatným záznamům
