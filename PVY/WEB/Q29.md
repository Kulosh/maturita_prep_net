# 29. AJAX (fetch)

> [!question] AJAX (fetch)
> Asynchronní komunikace ve webových stránkách, význam a použití. Rozdíl mezi synchronní a asynchronní komunikací, výhody asynchronního přístupu. Možnosti využití funkce fetch v JavaScriptu pro komunikaci se serverem. Odesílání požadavků metodami GET a POST, práce s hlavičkami a tělem požadavku. Zpracování odpovědí serveru, převod na JSON a další formáty. Praktické využití při načítání dat, ukládání údajů, práci s API a jiné.

---

## Co je to AJAX?

**AJAX** (Asynchronous JavaScript and XML) je technika, která umožňuje webovým stránkám komunikovat se serverem na pozadí bez nutnosti celou stránku znovu načítat. Přestože má v názvu XML, dnes se pro přenos dat používá téměř výhradně **JSON**.

---

## Synchronní vs. Asynchronní komunikace

### Synchronní komunikace
- Prohlížeč pošle požadavek a **čeká**, dokud server neodpoví.
- Během čekání je stránka „zamrzlá“ a uživatel nemůže nic dělat.
- Tradiční způsob načítání stránek.

### Asynchronní komunikace (Doporučeno)
- Prohlížeč pošle požadavek na pozadí a **pokračuje** ve vykonávání kódu.
- Jakmile data dorazí, spustí se funkce, která je zpracuje.
- Stránka zůstává plynulá a interaktivní.

>[!pros] Výhody asynchronního přístupu
>- **Rychlost:** Přenáší se jen malá část dat, ne celá stránka.
>- **UX (Uživatelský zážitek):** Žádné blikání stránky při každé akci.
>- **Úspora dat:** Šetří se výkon serveru i přenosové pásmo klienta.

---

## Funkce fetch

Moderní JavaScriptové API pro provádění síťových požadavků. Pracuje na principu **Promises** (slibů).

### Základní požadavek (GET)
Slouží k získání dat ze serveru.
```javascript
fetch('https://api.priklad.cz/data')
    .then(response => {
        if (!response.ok) throw new Error('Chyba sítě');
        return response.json(); // Převod odpovědi na objekt (JSON)
    })
    .then(data => {
        console.log('Získaná data:', data);
    })
    .catch(error => {
        console.error('Něco se nepovedlo:', error);
    });
```

---

## Odesílání dat (POST)

Slouží k odeslání nových dat na server (např. uložení uživatele). Vyžaduje nastavení objektu s možnostmi.

```javascript
const novyUzivatel = { jmeno: 'Aloy', role: 'Lovec' };

fetch('https://api.priklad.cz/users', {
    method: 'POST', // Metoda odeslání
    headers: {
        'Content-Type': 'application/json' // Říkáme serveru, že posíláme JSON
    },
    body: JSON.stringify(novyUzivatel) // Převod objektu na textový řetězec
})
.then(res => res.json())
.then(data => console.log('Uloženo:', data));
```

---

## Práce s odpovědí a JSON

Server obvykle odpovídá ve formátu JSON (JavaScript Object Notation). 
- `JSON.stringify(objekt)` – Převod z JS objektu na text (pro odeslání).
- `JSON.parse(text)` – Převod z textu na JS objekt (pro čtení).
- `response.json()` – Metoda ve fetch, která automaticky provede `JSON.parse` na těle odpovědi.

>[!warning] Bezpečnost a CORS
>Prohlížeče z bezpečnostních důvodů blokují požadavky na jiné domény, pokud to daný server výslovně nepovolí (tzv. **CORS** - Cross-Origin Resource Sharing).

---

## Praktické využití

1. **Načítání obsahu:** Nekonečné scrollování (Facebook, Instagram).
2. **Formuláře:** Odeslání dat bez obnovy stránky (kontaktní formuláře, chat).
3. **Live vyhledávání:** Výsledky se zobrazují hned, jak uživatel píše.
4. **API:** Propojení s externími službami (předpověď počasí, kurzy měn, mapy).

## Moderní zápis (Async/Await)

Místo řetězení `.then()` lze použít čitelnější zápis pomocí `async/await`.

```javascript
async function nactiData() {
    try {
        const response = await fetch('https://api.priklad.cz/data');
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.log('Chyba:', error);
    }
}
```
