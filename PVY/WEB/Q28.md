# 28. Časování skriptů

> [!question] Časování skriptů
> Časovače v JavaScriptu, princip a význam. Funkce setTimeout a setInterval, rozdíly mezi nimi a jejich praktické využití. Zrušení časovačů pomocí clearTimeout a clearInterval. Využití časovačů pro opakované nebo odložené provádění kódu, periodické aktualizace obsahu stránky, animace, odpočítávání, dynamické prvky a jiné. Možnosti kombinace časovačů s událostmi a dalšími částmi aplikace.

---

## Princip a význam časovačů

Časovače (Timers) umožňují v JavaScriptu spouštět kód s určitým časovým zpožděním nebo v pravidelných intervalech. Jsou klíčové pro asynchronní chování webu (věci se dějí „na pozadí“, zatímco uživatel může dál pracovat se stránkou).

---

## Funkce setTimeout (Jednorázové spuštění)

Spustí zadanou funkci **jednou** po uplynutí stanoveného času (v milisekundách).

**Syntaxe:**
```javascript
const timerId = setTimeout(funkce, zpozdeni_ms);
```

**Příklad:**
```javascript
setTimeout(() => {
    console.log('Tato zpráva se vypíše po 3 sekundách.');
}, 3000);
```

### Zrušení: clearTimeout
Pokud potřebujeme spuštění zrušit dříve, než nastane, použijeme ID, které funkce vrátila.
```javascript
const mojeId = setTimeout(() => alert('Baf!'), 5000);
clearTimeout(mojeId); // Už nebafne
```

---

## Funkce setInterval (Opakované spuštění)

Spouští zadanou funkci **opakovaně** v pravidelném intervalu.

**Syntaxe:**
```javascript
const intervalId = setInterval(funkce, interval_ms);
```

**Příklad (Jednoduché hodiny):**
```javascript
setInterval(() => {
    const nyni = new Date();
    console.log(nyni.toLocaleTimeString());
}, 1000);
```

### Zrušení: clearInterval
Zastaví opakování cyklu. **Vždy** by se mělo používat, aby kód neběžel na pozadí zbytečně (šetření paměti/výkonu).
```javascript
const stopky = setInterval(() => console.log('Tik'), 1000);
// Později...
clearInterval(stopky);
```

---

## Praktické využití

1. **Animace:** Postupná změna pozice nebo průhlednosti elementu.
2. **Odpočítávání:** Např. do začátku akce nebo konce platnosti slevy.
3. **Periodická aktualizace:** Načítání nových zpráv nebo kurzu měn bez obnovy stránky.
4. **Odložené reakce:** Např. vyhledávání začne až 500ms poté, co uživatel přestane psát (tzv. *Debouncing*).

>[!pros] Výhody časovačů
>- Zlepšení uživatelského zážitku (stránka působí živě).
>- Možnost automatizace úloh na pozadí.

>[!warning] Přesnost a výkon
>- Časovače v JS **nejsou 100% přesné**. Pokud je prohlížeč vytížen nebo je karta na pozadí, může dojít ke zpoždění.
>- Příliš krátké intervaly (např. 1ms) mohou drasticky zpomalit procesor a vybíjet baterii u mobilů.

---

## Kombinace s událostmi

Časovače se často spouští na základě akce uživatele.

**Příklad: Zmizení hlášky po 3 sekundách**
```javascript
const btn = document.querySelector('#save-btn');
const info = document.querySelector('#msg');

btn.addEventListener('click', () => {
    info.textContent = 'Uloženo!';
    
    // Po 3 sekundách text smažeme
    setTimeout(() => {
        info.textContent = '';
    }, 3000);
});
```
