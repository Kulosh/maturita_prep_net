# 26. JS – Práce s událostmi

> [!question] JS – Práce s událostmi
> Události v JavaScriptu – význam a využití. Typy událostí (kliknutí, pohyb myši, klávesnice, události okna aj.). Způsoby přiřazení obsluhy událostí - metoda addEventListener (doporučený způsob). Objekt události (event), důležité vlastnosti (clientX, clientY, key, altKey, ctrlKey a další). Princip bubbling, stopPropagation(), preventDefault().

---

## Význam a využití událostí

Události (Events) jsou signály, které vysílá prohlížeč nebo uživatel (např. kliknutí, posun stránky, stisk klávesy). JavaScript tyto signály zachytává a umožňuje na ně reagovat. Bez událostí by webové stránky byly statické a neinteraktivní.

---

## Typy událostí

1. **Události myši:**
    - `click` – Kliknutí levým tlačítkem.
    - `dblclick` – Dvojklik.
    - `mouseenter` / `mouseleave` – Myš vstoupila nad prvek / opustila ho.
    - `mousemove` – Pohyb myši nad prvkem.
2. **Události klávesnice:**
    - `keydown` – Klávesa byla stisknuta (opakuje se při držení).
    - `keyup` – Klávesa byla uvolněna.
3. **Události okna a dokumentu:**
    - `load` – Stránka byla kompletně načtena (včetně obrázků).
    - `DOMContentLoaded` – HTML je načteno a zparsováno (nečeká na obrázky).
    - `resize` – Změna velikosti okna.
    - `scroll` – Posun stránky.
4. **Události formulářů:**
    - `submit` – Odeslání formuláře.
    - `change` – Změna hodnoty (např. v selectu).
    - `input` – Každá změna v textovém poli (při psaní).

## Přiřazení obsluhy událostí

Existuje více způsobů, ale **addEventListener** je jediný správný pro moderní vývoj.

### 1. Metoda addEventListener (Doporučeno)
Umožňuje přiřadit více funkcí na jednu událost a lépe se spravuje.
```javascript
const btn = document.querySelector('button');

btn.addEventListener('click', function(e) {
    console.log('Tlačítko bylo stisknuto!');
});
```

>[!pros] Proč používat addEventListener?
>- Můžeš mít více reakcí na jedno kliknutí.
>- Můžeš událost kdykoliv odebrat pomocí `removeEventListener`.
>- Odděluje HTML od JavaScriptu.

### 2. HTML atributy (Zastaralé)
Nedoporučuje se, míchá se HTML s logikou.
```html
<button onclick="alert('Ahoj')">Klikni</button>
```

## Objekt události (Event Object)

Když nastane událost, prohlížeč vytvoří objekt obsahující podrobnosti o tom, co se stalo. Tento objekt se automaticky předává jako první parametr do funkce.

**Důležité vlastnosti:**
- `target` – Odkaz na element, na který se skutečně kliklo.
- `type` – Typ události (např. "click").
- **Souřadnice (u myši):**
    - `clientX`, `clientY` – Pozice myši vůči oknu prohlížeče.
    - `pageX`, `pageY` – Pozice myši vůči celé stránce.
- **Klávesnice:**
    - `key` – Název klávesy (např. "Enter", "a").
    - `code` – Fyzický kód klávesy.
    - `altKey`, `ctrlKey`, `shiftKey` – Pravdivostní hodnota, zda byla daná klávesa držena.

>[!example] Praktická ukázka práce s objektem `event`
>```javascript
>// Sledování pohybu myši a výpis souřadnic
>document.addEventListener('mousemove', (e) => {
>    console.log(`Myš je na pozici: X=${e.clientX}, Y=${e.clientY}`);
>});
>
>// Reakce na klávesnici (např. zavření okna při ESC)
>window.addEventListener('keydown', (e) => {
>    if (e.key === 'Escape') {
>        console.log('Stiskl jsi ESC!');
>    }
>    if (e.ctrlKey && e.key === 's') {
>        e.preventDefault(); // Zabrání uložení stránky prohlížečem
>        console.log('Ukládám data vlastní funkcí...');
>    }
>});
>```

## Princip Bubbling (Probublávání)

Když nastane událost na elementu (např. `<span>`), událost se pak šíří nahoru k jeho rodičům (`<div>` -> `<body>` -> `document` -> `window`), dokud ji někdo nezastaví.

>[!info] Bubbling vs. Capturing
>- **Bubbling:** Od nejmenšího prvku nahoru (standard).
>- **Capturing:** Od nejvyššího prvku dolů k cíli (méně časté).

### Zastavení šíření: stopPropagation()
Zabrání tomu, aby se událost šířila k rodičům.
```javascript
btn.addEventListener('click', function(e) {
    e.stopPropagation(); // Rodiče se o kliknutí nedozví
});
```

>[!warning] Pozor na bubbling
>Pokud máš tlačítko uvnitř odkazu, kliknutí na tlačítko spustí i událost na odkazu. V takových případech je nutné použít `e.stopPropagation()`.

---

## Zrušení výchozí akce: preventDefault()

Mnoho událostí má v prohlížeči výchozí chování (např. odkaz se otevře, formulář se odešle a stránka se obnoví). Metoda `preventDefault()` toto chování zruší.

```javascript
const link = document.querySelector('a');

link.addEventListener('click', function(e) {
    e.preventDefault(); // Odkaz se neotevře
    console.log('Zůstali jsme na stránce!');
});
```
