# 10. MS Access, MS Excel – exporty a importy dat

> [!question] MS Access, MS Excel – exporty a importy dat
> Kam lze data z Accessu exportovat (např. Excel, textové soubory, CSV, XML) a jakým způsobem, a odkud lze data do Accessu importovat (např. Excel, CSV, jiné databáze, textové soubory) a jak, požadavky na strukturu textového souboru pro úspěšný import: typy souborů (XLSX, CSV, XML), oddělovače, názvy polí, datové typy.

---

## Exporty z MS Access

Export slouží k převedení dat z databáze (tabulek nebo dotazů) do jiných formátů pro další zpracování nebo prezentaci.

**Kam lze exportovat:**
- **MS Excel (.xlsx):** Zachování struktury, vhodné pro výpočty a grafy.
- **Textové soubory (.txt, .csv):** Univerzální formát pro jiné systémy.
- **XML:** Pro výměnu dat mezi aplikacemi a webovými službami.
- **PDF / XPS:** Pro tisk a sdílení bez možnosti úprav.
- **Jiné databáze:** Například přes rozhraní ODBC nebo do jiného souboru Accessu.

>[!pros] Výhody exportu do Excelu
>- Možnost využít pokročilé formátování a grafy, které Access neumí tak dobře.
>- Snadné sdílení dat s lidmi, kteří nemají Access.

**Způsob exportu:**
Karta **Externí data** -> skupina **Exportovat**. Lze exportovat celou tabulku nebo výsledek dotazu.

---

## Importy do MS Access

Import umožňuje načíst externí data do databáze jako novou tabulku nebo je připojit k existující tabulce.

**Odkud lze importovat:**
- **MS Excel:** Nejčastější zdroj.
- **Textové soubory (CSV, TXT):** Import pomocí průvodce, kde definujeme oddělovače.
- **Soubory XML.**
- **Jiné databáze:** Import tabulek z jiného `.accdb` souboru.
- **Služby SharePoint nebo SQL Server.**

### Rozdíl mezi importem a propojením (Link)
- **Import:** Data se zkopírují do Accessu. Pokud se změní zdroj (např. Excel), v Accessu zůstanou stará data.
- **Propojení (Linked Table):** Access na data pouze odkazuje. Pokud změníš data v Excelu, v Accessu se ihned projeví (a často i naopak).

## Požadavky na strukturu pro úspěšný import

Aby import proběhl bez chyb (např. "Import Errors"), musí data splňovat určitá pravidla.

### 1. Názvy polí (Hlavička)
- První řádek by měl obsahovat názvy sloupců.
- Názvy by měly být unikátní a bez speciálních znaků (tečky, mřížky), které by Accessu mohly vadit.

### 2. Datové typy
- Access při importu kontroluje, zda jsou data v celém sloupci stejného typu (např. všechno čísla, všechno data).
- Pokud je v číselném sloupci text, import u těchto řádků selže.

### 3. Oddělovače (pro CSV/TXT)
- **Oddělený formát:** Pole jsou oddělena znakem (středník, čárka, tabulátor).
- **Pevná šířka:** Každé pole má pevně daný počet znaků (dnes méně časté).
- Je nutné správně nastavit **kódování** (např. UTF-8), aby se nepokazila čeština (diakritika).

### 4. Primární klíč
- Během importu se Access zeptá, zda má vytvořit primární klíč (ID), nebo zda má použít existující sloupec.

>[!warning] Časté chyby při importu
>- **Záměna datových typů:** Access se snaží odhadnout typ podle prvních pár řádků. Pokud je na 1000. řádku jiný formát, hodí to chybu.
>- **Otevřený soubor:** Pokud importuješ z Excelu, nesmí být ten soubor zrovna otevřený v Excelu.
>- **Chybějící data:** Prázdné buňky v polích, která jsou v Accessu nastavena jako "Povinná".
