# Příprava na maturitu - SPS

Tohle repo slouží na ukládání zápisků z přípravy na maturitu T4.C z roku 2025/2026.

Rozdělení repa je na [SPS](/SPS/SPS_okruh.md) a [PVY](/PVY/PVY-SPS_Okruh.md).

## Recommendation

Je doporučeno používat buď

1. [Obsidian](https://obsidian.md/) s přiloženými styly ve složce [Snipety](/Snipety) a zaponout je pomocí [návodu](/Snipety/Snipety.md)
2. VS Code s rozšířením [Markdown Preview Enhanced](https://marketplace.visualstudio.com/items?itemName=shd101wyy.markdown-preview-enhanced) od [Yiyi Wang](https://marketplace.visualstudio.com/publishers/shd101wyy)
