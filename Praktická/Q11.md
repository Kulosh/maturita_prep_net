# Práce s třídami

- třída je základní stavební prvek objektově orientovaného programování
- je to šablon nebo plán, podle kterého se vytvářejí objekty

## Třída popisuje:
- vlastnosti (atributy) -- jaká data objekt obsahuje
- metody -- co objekt umí dělat

Například třída `Auto` může obsahovat:
- značku, barvu, rychlost...
- a jeho metody můžou být: jet, brzdit...

```csharp
public class Auto
{
	public string Značka { get; set; }
	public string Barva { get; set; }
	public int Rychlost { get; set; }
	
	public void Rychlost()
	{
	
	}
	
	public void Brzdi(string rychlost)
	{
	
	}
}
```

> [!t] How to
> - musíme si vytvořit úplně novou třídu a pojmenovat jí **Auto**
> - takže tato třída popisuje, že každý objekt **Auto** bude mít: značku, rychlost, barvu a může používat metody rychlost a brždění
> - **clasu Auto píšu mimo clasu Program**

## Objekt
- je konkrétní instance třídy
- jednoduše: 
	- třída = plán domu
	- objekt = skutečný postavený dům

### Vytvoření objektu:
```csharp
internal class Program
{
	static void Main(string[] args)
	{
		Auto mojeAuto = new Auto();
	}
}
```

- `Auto` = název třídy
- `mojeAuto` = název proměnné
- `new Auto()` = vytvoří nový objekt

### Nastavení hodnot:
#### Po vytvoření:
```csharp
mojeAuto.Značka = "BMW";
mojeAuto.Barva = "bílá";
mojeAuto.Rychlost = 120;
```

#### Při vytvoření bez konstruktoru
```csharp
Auto mojeAuto = new Auto(){
	Značka = "BMW",
	Barva = "bílá",
	Rychlost = 120
}
```

### Metody
- metoda je funkce definovaná ve třídě
- určuje chování objektu
- například auto může: jet, zastavit, zrychlit

**Příklad metody:**

```csharp
public void Rychlost()
{
	Rychlost += 10;
}
```
- tato metoda přidá rychlost autu +10

```csharp
mojeAuto.Rychlost();

Console.WriteLine(mojeAuto.Rychlost);
```
- `mojeAuto.rychlost()` = aplikuje metodu na mojeAuto
- `Console.WriteLine(mojeAuto.Rychlost);` = vypíše mojeAuto

## Abstrakce objektů
- abstrakce je jeden ze základních principů OOP
- znamená zjednodušení systému tak, že zobrazujeme jen důležité vlastnosti objektu a skrýváme složitou implementaci
- například:
	- řidič používá -- volant, pedály, brzdu...
	- ale neřeší -- jak funguje motor, jak pracuje převodovka...
	- a to je právě **abstrakce** v OOP

### Abstraktní třídy
- abstraktní třída je třída, která slouží jako základ pro jiné třídy
- nelze z ní vytvořit objekt přímo
- používá se tehdy, když chceme vytvořit obecný model, ze kterého budou dědit jiné třídy

Příklad:
```csharp
abstract class Zvire
{
	public abstract string Name { get; }
	
	public abstract void Zvuk();
}
```

- abstract class = abstraktní třída
- obsahuje abstraktní metodu

Objekt nelze vytvořit :

![](/Praktická/imgs/Q11/media/image24.png)

### Abstraktní metoda
- je to metoda, která nemá implementaci, pouze říká, že metoda musí existovat
- implementaci musí vytvořit potomci (dědičné třídy)

```csharp
public abstract void Zvuk();
```

- metoda pouze říká, že každé zvíře musí mít nějaký zvuk, ale jaký přesně, to už určí konkrétní zvíře

### Implementace v potomcích
- když třída dědí z abstraktní třídy, musí implementovat abstraktní metody
- používá se klíčové slovo **override**

```csharp
public class Pes : Zvire
{

	public override void Zvuk()
	{
		Console.WriteLine("haf");
	}
}
```

`Pes : Zvire` = dědičnost
`override` = přepsání metody ( v tuto chvíli jen Pes má tento kód v metodě)

```csharp
static void Main(string[] args)
{
	Pes pes = new Pes();
	pes.Zvuk();
}
```

Konzole:
```console
haf
```

- můžeme dědit více tříd
```csharp
public class Kočka : Zvire
{
	public override void Zvuk()
	{
		Console.WriteLine("mňau");
	}
}
```

- **zjednodušeně**: override umožňuje přepisovat metody a každá třída, která tuto třídu dědí kde je tato metoda ji může přepsat podle toho, jak je potřeba
- **zjednodušeně Abstrakce** :
Abstraktní třída je základní šablona pro jiné třídy, která definuje společné vlastnosti a metody, ale některé metody nechává nedokončené, aby je implementovaly potomci.

## Rozhraní
- je speciální typ v objektové orientovaném programování, který definuje pouze metody nebo vlastnosti, ale neobsahuje jejich implementaci
- třída musí tyto metody obsahovat, ale jak budou fungovat, si určí sama

Syntaxe:
```csharp
internal interface ILetajici
{
	void Let()
}
```

- zapisuje se pomocí klíčového slova `interface`
- tvoří se jako samostatná třída, ale nechová se jako běžná třída !!!

### Implementace rozhraní:

```csharp
public class Ptak : ILetajici
{
	public void Let()
	{
		Console.WriteLine("Pták letí");
	}
}
```

- implementuje se pomocí dvojtečky  `:`, rozhraní má světle zelenou barvu

```csharp
public class Ptak : ILetajici, Hnusny
{
	public void Let()
	{
		Console.WriteLine("Pták letí");
	}
	
	public void Zlý()
	{
		Console.WriteLine("Pták je zlej");
	}
}
```

- třída může implementovat i více rozhraní zároveň

#### Shrnutí rozhraní:
- rozhraní definuje metody a vlastnosti
- neobsahuje jejich implementaci
- třídy je musí implementovat

#### Používá se pro:
- sjednocení chování tříd
- flexibilní návrh programů
- podporu polymorfismu

## Rozhraní vs Abstraktní třída

### Abstraktní třída:
- může obsahovat implementaci
- může mít proměnné
- třída může dědit jen jednou
- slouží jako základní třída

### Rozhraní:
- většinou neobsahuje implementaci
- nemůže mít proměnné
- můžeme implementovat více rozhraní

### Zjednodušeně:
- *Abstraktní třída* = je částečně hotová třída (šablona), která může obsahovat kód
- *Rozhraní* = je jen seznam metod, které musí třída implementovat
- Abstraktní třída = v děděné třídě musíme použít metody jen ty, které mají třídu **Abstract**
- Rozhraní = v třídě co ho využívá musíme použít všechny jeho metody

#### Zapouzdření
- je jeden ze základních principů OOP
- znamená skrytí vnitřních dat objektu a řízení přístupu k nim pomocí metod nebo vlastností

##### Důvod použití:
- zapouzdření chrání data před: nechtěnou změnou, chybami v programu, přímým přístupem zvenku

**Příklad bez zapouzdření:**
```csharp
public class BankovniUcet
{
	public int zustatek
}

BankovniUcet ucet = new BankovniUcet();

ucet.zustatek = -1000000000;
```

- to je problém, protože někdo může nastavit nesmyslnou hodnotu

##### Příklad se zapouzdřením:

```csharp
public class BankovniUcet
{
	private int zustatek;
	
	public void Vloz(int castka) 
	{
		// zde by mohla být nějaká kontrola třeba aby nebyl záporný
		zustatek += castka;
	}
	
	public void ZiskejZustatek() 
	{
		return zustatek;
	}
}

BankovniUcet ucet = new BankovniUcet();
// Toto už nebude fungovat protože není přístup k privátním vlastnostem
ucet.zustatek = -1000000000; 
```
 - pomocí **private** je teď zůstatek skrytý a lze ho měnit jen přes metody

##### Zapouzdření pomocí vlastností
```csharp
public class Auto 
{
	private int rychlost;
	
	public int Rychlost
	{
		get { return rychlost; }
		set 
		{
			if (value >= 0)
				rychlost = value;
		}
	}
}
```

- get -> vrací hodnotu
- set -> nastavuje hodnotu, ale může kontrolovat podmínky

#### Modifikátory přístupu

- zapouzdření funguje pomocí modifikátorů přístupu

##### Public
``` csharp
public class Auto
{
	public string Nazev;
}
```

- přístup je povolen odkudkoliv

##### Private
``` csharp
public class Auto
{
	private string Nazev;
}
```

- přístup je povolen pouze uvnitř třídy

##### Protected
``` csharp
public class Auto
{
	protected string Nazev;
}
```

- přístup je povolen pouze v potomcích třídy

##### Internal
``` csharp
public class Auto
{
	internal string Nazev;
}
```

- přístup je povolen v rámci projektu

### Shrnutí:
*Zapouzdření znamená:*
- skrytí vnitřních dat objektu
- řízení přístupu k datům
- ochranu před chybami

*Používá se pomocí:*
- private proměnných
- metod
- vlastností
- modifikátorů přístupu

## Dědičnost
- je to princip OOP, který umožňuje vytvořit novou třídu na základě již existující třídy
- nová třída: dědí vlastnosti, dědí metody

Příklad:
```csharp
public class Zvire
{
	public string Name { get; set; }
	public string Description { get; set; }
}
```

- zvíře je původní třída

```csharp
public class Pes : Zvire
{
	public void Stekot()
	{
		Console.WriteLine("Haf");
	}
}
```

- toto je třída, která dědí
- v tuto chvíli může pes používat metody zděděné z classy Zvíře a může vytvářet své metody
- výhody:
	- znovupoužití kódu
	- přehlednější struktura programu
	- jednodušší rozšiřování systému

## Polymorfismus
- polymorfismus, znamená, že stejná metoda může mít různé chování podle objektu

Tvoření:
```csharp
public class Zvire
{
	public virtual void Zvuk()
	{
		Console.WriteLine("Zvuk");
	}
}
```

- máme nějakou třídu, která má metodu
- před metodu napíšeme **virtual** což zajistí, že děděné třídy tuto metodu mohou přepsat a upravit si jí podle sebe

```csharp
public class Pes : Zvire
{
	public override void Zvuk()
	{
		Console.WriteLine("Haf");
	}
}
```

```csharp
public class Kocka : Zvire
{
	public override void Zvuk()
	{
		Console.WriteLine("Mňau");
	}
}
```

- je použita stejná metoda akorát metoda dělá pokaždé něco jiného

```csharp
static void Main(string[] args)
{
	Pes pes = new Pes();
	pes.Zvuk();
	
	Kocka kocka = new Kocka();
	kocka.Zvuk();
}
```

Výstup:
```console
Haf
Mňau
```

> [!tip] Něco navíc
> V některých případech je dobré mít základ a rozšíření:
> ```csharp
> public class Uzivatel
>{
>	public virtual void Prihlaseni()
>	{
>		Console.WriteLine("Uživatel se přihlásil");
>			// nebo nějaká logika pro přihlášení
>	}
>}
> ```
> A potom mohu:
> ```csharp
> public class Admin : Uzivatel
>{
>	public override void Prihlaseni()
>	{
>		base.Prihlaseni(); // důležité - zachová základní chování
>		Console.WriteLine("Načítám admin panel...");
>	}
>}
> ```
> Výstup pak bude:
> ```Console
> Uživatel se přihlásil  
> Načítám admin panel...
> ```

### Shrnutí:
**virtual** = dovoluje metodu přepsat pro potomky
**abstract** = nutí potomky metodu implementovat
**override** = přepisuje metodu u potomků

## Kolekce (většina otázky probraná v [předchozí otázce](Q10.md#8.%20Datové%20struktury))
- slouží k ukládání více objektů nebo hodnot do jedné proměnné

### List (seznam)
- kolekce, která ukládá více hodnot stejného typu

#### Tvoření:
```csharp
List<string> jmena = new List<string>();
```
- toto je seznam do kterého ukládáme stringy

#### Přidávání:
```csharp
jmena.Add("Martin");
jmena.Add("Jirka");
```

#### Odebírání:
```csharp
jmena.Remove("Jirka");
```

#### Přístup podle indexu
- indexuje se od 0, takže první prvek je 0
```csharp
Console.WriteLine(jmena[0]);
```

- vypíše: Martin

### Kolekce objektů
- kolekce může obsahovat také objekty tříd

```csharp
List<Zvire> zvirata = new List<Zvire>();
```

- vytvořil jsem list, který uchovává objekty z třídy Zvíře

```csharp
List<Zvire> zvirata = new List<Zvire>();

// přidá do pole a vytvoří nové Zvíře, co se jmenuje Max
zvirata.Add(new Zvire { Name = "Max" });

// vytváření objektů, když máme konstruktor ve třídě Zvíře
zvirata.Add(new Zvire("Filip"));
```
