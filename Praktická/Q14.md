# Úvod do GDI+

GDI+ (Graphics Device Interface) je rozhraní v .NET, které umožňuje vykreslovat 2D grafiku, obrázky a text. Vše probíhá pomocí objektu **Graphics**, což je v podstatě "virtuální plátno".

## Kde kreslit?
Nejčastěji se kreslí v události **Paint** (formuláře nebo komponenty `PictureBox`). Tato událost se volá pokaždé, když je potřeba okno překreslit (např. při změně velikosti nebo minimalizaci).

```csharp
private void Form1_Paint(object sender, PaintEventArgs e)
{
    // Objekt Graphics získáme z argumentů události
    Graphics g = e.Graphics;
    
    // Zapnutí vyhlazování (vypadá to mnohem líp) ale neukazovali jsme si
    g.SmoothingMode = System.Drawing.Drawing2D.SmoothingMode.AntiAlias;
}
```

> [!important] Vynucení překreslení
> Pokud chceš něco překreslit (např. po kliknutí na tlačítko), nikdy nevolej `Paint` přímo. Použij metodu `Invalidate();` (formulář) nebo `pictureBox1.Invalidate();`.

# Nástroje: Pero a Štětec

Před kreslením si musíme připravit nástroje. Rozlišujeme dva základní typy:

| Nástroj | Třída | Použití |
| :--- | :--- | :--- |
| **Pero** | `Pen` | Čáry a obrysy (metody `Draw...`) |
| **Štětec** | `Brush` | Výplně ploch (metody `Fill...`) |

## Příklad vytvoření nástrojů
```csharp
Pen modrePero = new Pen(Color.Blue, 2); // Barva a tloušťka
SolidBrush cervenyStetec = new SolidBrush(Color.Red);

// Použití
g.DrawRectangle(modrePero, 10, 10, 100, 50);  // Jen obrys
g.FillRectangle(cervenyStetec, 120, 10, 100, 50); // Jen výplň
```

# Kreslení základních objektů

Všechny metody kreslení mají parametry `(nástroj, x, y, šířka, výška)`.

- **Úsečka:** `g.DrawLine(pero, x1, y1, x2, y2);`
- **Obdélník:** `g.DrawRectangle(pero, x, y, w, h);`
- **Elipsa/Kruh:** `g.DrawEllipse(pero, x, y, w, h);`
- **Text:** `g.DrawString("Ahoj", font, stetec, x, y);`

```csharp
Font mujFont = new Font("Arial", 12, FontStyle.Bold);
g.DrawString("Maturita 2026", mujFont, Brushes.Black, 50, 50);
```

# Transformace souřadnic

Standardně je bod `[0,0]` v levém horním rohu a osa `Y` míří dolů. To je pro matematické grafy nepraktické.

## Posun a otočení
- `g.TranslateTransform(x, y);` – Posune počátek souřadnic (např. do středu formuláře).
- `g.RotateTransform(uhel);` – Otočí celé plátno o daný úhel.

```csharp
// Posun do středu formuláře
g.TranslateTransform(this.Width / 2, this.Height / 2);

// Teď je [0,0] uprostřed okna
g.DrawLine(Pens.Black, -100, 0, 100, 0); // Osa X
g.DrawLine(Pens.Black, 0, -100, 0, 100); // Osa Y
```

# Zobrazování matematických funkcí

Při kreslení funkcí (např. `sin(x)`) musíme vyřešit dvě věci:
1. **Měřítko:** Matematické hodnoty jsou malé (0 až 1), pixely velké (stovky). Musíme násobit.
2. **Osa Y:** V grafice míří dolů, v matematice nahoru. Musíme násobit `-1`.

## Příklad vykreslení Sinusovky
```csharp
private void VykresliSinus(Graphics g)
{
    Pen p = new Pen(Color.Green, 2);
    g.TranslateTransform(50, 200); // Posun na "začátek" osy

    float staraX = 0, staraY = 0;

    for (float x = 0; x < 500; x += 1) // x jsou pixely na obrazovce
    {
        // Výpočet Y: sin(x/meritko) * amplituda * -1 (kvůli otočení osy Y)
        float y = (float)Math.Sin(x / 20.0) * 50 * -1;

        if (x > 0)
            g.DrawLine(p, staraX, staraY, x, y);

        staraX = x;
        staraY = y;
    }
}
```

# Práce s plátnem (Bitmap)

Pokud chceme grafiku uložit nebo kreslit "do zásoby", použijeme objekt `Bitmap`.

```csharp
// Vytvoření prázdného obrázku
Bitmap bmp = new Bitmap(800, 600);
// Vytvoření Graphics objektu pro tento obrázek
Graphics gBmp = Graphics.FromImage(bmp);

gBmp.Clear(Color.White);
gBmp.FillEllipse(Brushes.Green, 10, 10, 50, 50);

// Uložení na disk
bmp.Save("obrazek.png", System.Drawing.Imaging.ImageFormat.Png);
```

> [!info] Tip pro maturitu
> Nezapomeň na `using System.Drawing;` a `using System.Drawing.Drawing2D;` na začátku souboru!
