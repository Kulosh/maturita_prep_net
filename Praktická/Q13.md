# Práce se soubory

Pro práci se soubory v .NET používáme jmenný prostor `System.IO`.

## Zápis do souboru (`StreamWriter`)
Slouží k ukládání textových dat na disk.

```csharp
using System.IO;

// Zápis textu
string cesta = "data.txt";
using (StreamWriter sw = new StreamWriter(cesta, false)) // false = přepsat, true = připsat na konec
{
    sw.WriteLine("První řádek");
    sw.WriteLine("Druhý řádek");
}
```

## Čtení ze souboru (`StreamReader`)
Slouží k načítání dat řádek po řádku.

```csharp
using (StreamReader sr = new StreamReader("data.txt"))
{
    string radek;
    while ((radek = sr.ReadLine()) != null)
    {
        Console.WriteLine(radek);
    }
}
```

## Ošetření výjimek (`try-catch`)
Při práci se soubory může dojít k chybě (soubor neexistuje, je používán jiným programem). Proto používáme blok `try-catch`.

```csharp
try 
{
    string text = File.ReadAllText("neexistuje.txt");
}
catch (FileNotFoundException ex)
{
    MessageBox.Show("Soubor nebyl nalezen!");
}
catch (Exception ex)
{
    MessageBox.Show("Nastala obecná chyba: " + ex.Message);
}
```

# Práce s databází

Pro připojení k databázi potřebujeme **Connection String**, který obsahuje adresu serveru, název databáze a přihlašovací údaje.

## Connection String (Příklad MySQL)
```csharp
// Ukázka connection stringu pro MySQL
string connString = "Server=localhost;Database=moje_db;Uid=root;Pwd=heslo123;";

// Příklad vytvoření spojení (vyžaduje knihovnu MySql.Data)
using (MySqlConnection conn = new MySqlConnection(connString))
{
    conn.Open();
    // Zde se provádějí dotazy...
}
```

> [!info] Tip pro maturitu
> Pokud nemáme přístup k reálnému SQL serveru, často se používá **DataTable** jako "dočasná databáze" v paměti programu.

# Oddělení dat od vizuálu (DataTable)

`DataTable` je objekt, který drží data v paměti nezávisle na tom, jak jsou zobrazená. Je to tabulka složená z `DataColumn` (sloupce) a `DataRow` (řádky).

## Vytvoření tabulky v kódu
```csharp
DataTable dt = new DataTable();

// Definice sloupců
dt.Columns.Add("Id", typeof(int));
dt.Columns.Add("Jmeno", typeof(string));
dt.Columns.Add("Vek", typeof(int));

// Přidání řádku
dt.Rows.Add(1, "Jan Novák", 20);
dt.Rows.Add(2, "Petr Svoboda", 22);
```

# Zobrazování dat (DataGridView)

`DataGridView` je komponenta WinForms, která slouží k zobrazení tabulkových dat uživateli.

## Napojení DataTable na Grid
Nejrychlejší způsob, jak zobrazit data, je nastavit vlastnost `DataSource`.

```csharp
// Propojení s vytvořenou tabulkou
dataGridView1.DataSource = dt;
```

> [!important] Výhoda oddělení dat
> Když změníme data v `DataTable`, změny se automaticky (nebo po refreshy) promítnou do `DataGridView`. Vizuální prvek (Grid) se stará jen o zobrazení, zatímco logika (DataTable) drží samotné hodnoty.

---

# Příklad: Načtení CSV do Gridu
Kombinace čtení ze souboru a zobrazení v tabulce.

```csharp
DataTable dt = new DataTable();
dt.Columns.Add("Jmeno");
dt.Columns.Add("Vek");

string[] radky = File.ReadAllLines("uzivatele.csv");
foreach (string radek in radky)
{
    string[] bunky = radek.Split(';'); // Rozdělení řádku podle středníku
    dt.Rows.Add(bunky[0], bunky[1]);
}

dgvData.DataSource = dt;
```
