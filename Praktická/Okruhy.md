# [Maturitní témata – Praktická maturitní zkouška (2025/2026)](/Praktická/Okruhy.md)

**Obor:** Informační technologie  
**Specializace:** Správa počítačových sítí (SPS), Programování a databázové systémy (PDS), Grafické systémy a tvorba webových stránek (GWB)

---

## Blok témat pro všechna zaměření (Společný základ)

### [1. Základy správy operačního systému](/Praktická/Q1.md)
MS-Windows – instalace a konfigurace OS, administrátorské nástroje, zabezpečení souborů a složek, správa uživatelů, konzole kořenového adresáře, základní práce s příkazovým řádkem, základní nastavení sítě.

### 2. MS-Office
*   **MS-Word:** Formátování (písmo, odstavec, oddíly), styly, práce s velkými dokumenty (osnova, rejstřík, seznam obrázků, obsah), hromadná korespondence, tvorba maker, šablony, formuláře.
*   **MS-PowerPoint:** Vkládání objektů, předlohy a návrhy snímků, animace, přechody, nastavení prezentace.
*   **MS-Excel:** Operace s buňkami/listy, funkce (datumové, logické, statistické, textové, vyhledávací, matematické), grafy (elementární funkce, 2D/3D, burzovní), práce se seznamy (třídění, filtry, kontingenční tabulky), tvorba a úprava maker ve VBA, ovládací prvky.
*   **MS-Access:** Tvorba tabulek (datové typy, relace, import/export, filtry), dotazy (výběrové, křížové, akční), formuláře a podformuláře, ovládací prvky, makra a moduly, sestavy, úprava maker ve VBA.

### 3. AutoCAD 2D
Uživatelské prostředí, konfigurace, typy čar (*.lin), kreslící a editační nástroje, hladiny a standardy, výkresový prostor, šrafování (*.pat), zpracování textu a tabulek, kótování, atributy, bloky (klasické, dynamické), externí reference (XREF), Design Center, tisk a publikování (PDF, DWF), uživatelské úpravy (CUI).

### 4. AutoCAD 3D & Inventor
*   **AutoCAD 3D:** Pohledy, USS, tvorba těles (primitiva, vytažení, rotace, tažení, šablonování), boolean operace, editace těles a ploch.
*   **Inventor:** Parametrické modelování, náčrty (vazby, kótování), modelování součástí, sestavy (3D vazby, normalizované součásti), vizualizace (materiály, animace), generování výkresů.

### 5. Adobe Photoshop
Barevné modely (RGB, CMYK), nástroje pro malování, přechody, masky a alfa kanály, práce s vrstvami (ořezové skupiny, vrstvy úprav), cesty a vektorové masky, retušování, textové efekty, globální úpravy obrazu a filtry.

### 6. Konfigurace sítě na platformě Windows
Konfigurace stanice (uživatelé, práva, sdílení, NTFS, místní zásady), sítě klient-server (instalace Windows Serveru s/bez AD, profily uživatelů – místní, cestovní, povinné, domovské adresáře), Group Policy (GPO), dynamické disky, objekty a práva v Active Directory.

### 7. Základní síťové služby (Windows)
DNS server (primární, sekundární, domény, klient), DHCP služba (server, relay agent, klient), směrování (statické a dynamické RIP).

### 8. Další síťové služby (Windows)
Webový server IIS (HTTP, HTTPS, SSL), ověřování uživatelů (anonymní, Windows, AD), FTP server (IIS), poštovní server (Kerio Mail Server – SMTP, POP3, IMAP, SSL), konfigurace poštovních klientů.

### 9. Linux – Základy a služby
Instalace (CLI/GUI), správa uživatelů, diskový a souborový systém, konfigurace sítě. Základní nastavení služeb DNS, DHCP a webserveru Apache.

### [10. Základy programování](/Praktická/Q10.md)
Datové struktury a typy, konverze, vstup/výstup, procedury a funkce (parametry), operátory, rozhodovací konstrukce, cykly (for, while, foreach), pole, řetězce, dynamické struktury.

### 11. Objektově orientované programování (OOP)
Třídy, metody, vlastnosti, konstruktory. Abstrakce (abstraktní třídy/metody), rozhraní (interface), zapouzdření (modifikátory přístupu), dědičnost, polymorfismus. Kolekce (přidávání, procházení, mazání).

### 12. GUI – Windows Forms
Přehledové a editační formuláře, DialogResult, validace dat, komponenty (TextBox, Label, Button, ListBox, ComboBox), události (Click, Load).

### 13. Práce s daty
Práce se soubory (čtení, zápis, výjimky), práce s databází (MSSQL/MySQL), zobrazování v gridech (DataGrid), oddělení dat od vizuálu (DataTable).

### 14. GDI+ grafika
Kreslení základních objektů (úsečka, elipsa, obdélník, text), transformace souřadnic, zobrazování matematických funkcí, objekt Graphics, práce s plátnem.

### 15. Tvorba webu v .NET
MVC architektura (View, Controller), šablony (Layout), parametry HTTP, formuláře (GET/POST), validace, Entity Framework (ORM), JSON, REST API, zabezpečení (přihlašování, Session).

### 16. MS-SQL
Návrh DB, tabulky, klíče (PK, FK), reference, constrainty (CHECK, DEFAULT), indexy. Skripty a metadata. Vlastní funkce (skalární, tabulkové), křížové dotazy, DML a DDL příkazy, uložené procedury, triggery.

### 17. Základy tvorby webu
*   **HTML:** Sémantické elementy, struktura, tabulky, formuláře.
*   **CSS:** Selektory, jednotky, Flexbox, Grid, pseudotřídy.
*   **JavaScript (Frontend):** DOM, události, validace, časování, úložiště (LocalStorage).
*   **Backend:** Node.js, Express.js, TypeScript, REST API, AJAX (fetch), GET/POST, databáze, zabezpečení.

## Specializace: Správa počítačových sítí (SPS)

### 18. Pokročilé síťové služby (Windows)
Zabezpečený vzdálený přístup, certifikační služba (CA, vydávání certifikátů), IIS na HTTPS, FTP s SSL.

### 19. Produkty třetích stran
FileZilla (Server/Client, SSL), poštovní klienti (Outlook, Thunderbird), šifrování a certifikáty v poště, Apache v prostředí Windows (konfigurace SSL).

### 20. Konfigurace systému Linux
Přístupová práva (ACL), RAID pole, správa svazků (LVM), zálohování, sudo (spouštění pod jinou identitou), instalace software (balíčky vs. zdrojové kódy).

### 21. Síťové služby v Linuxu
DNS (dopředná/reverzní zóna), DHCP, FTP server, Apache (v Linuxovém prostředí).
