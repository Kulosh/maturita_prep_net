# Události (Events)

Slouží k reakci na činnost v programu (kliknutí, načtení...).

## Form Load
Událost, která se spustí při otevření (načítání) formuláře. Používá se pro inicializaci, načtení dat nebo naplnění seznamů.

```csharp
private void Form1_Load(object sender, EventArgs e)
{
    name_label.Text = "Vítej v apce";
}
```

## Button Click
Událost vyvolaná kliknutím na tlačítko.

**Příklad:** Vypisování jména z TextBoxu do MessageBoxu.
![](/Praktická/imgs/Q12/image14.png)

```csharp
private void name_button_Click(object sender, EventArgs e)
{
    string jmeno = name_textBox.Text;
    MessageBox.Show("ČUS! " + jmeno);
}
```

# Práce s více formuláři

Druhý formulář přidáme přes pravé tlačítko na projekt -> **Add** -> **Form (Windows Forms)**.

![](/Praktická/imgs/Q12/image19.png)

## Otevírání druhého formuláře
Máme-li `Form1` a `Form2`, můžeme druhý otevřít takto:

```csharp
private void form2_button_Click(object sender, EventArgs e)
{
    Form2 f2 = new Form2();
    f2.Show();       // Otevře okno a program pokračuje (můžeme dál klikat v Form1)
    // f2.ShowDialog(); // Otevře okno a čeká na jeho zavření (Form1 je zablokován)
}
```

# DialogResult

`DialogResult` je informace o tom, jak uživatel formulář zavřel (např. OK vs. Cancel).

## Nastavení ve Form2
U tlačítka pro potvrzení nastavíme:
```csharp
private void ok_button_Click(object sender, EventArgs e)
{
    this.DialogResult = DialogResult.OK;
}
```

U tlačítka pro zrušení:
```csharp
private void cancel_button_Click(object sender, EventArgs e)
{
    this.DialogResult = DialogResult.Cancel;
}
```

## Zpracování ve Form1
Zde zjistíme, co uživatel ve druhém okně udělal:

```csharp
Form2 f2 = new Form2();
if (f2.ShowDialog() == DialogResult.OK)
{
    MessageBox.Show("Uživatel potvrdil");
}
else
{
    MessageBox.Show("Uživatel zrušil");
}
```

# Validace dat

Kontrola, zda uživatel zadal data ve správném formátu.

## Validace formuláře (při odeslání)
Provádíme v události kliknutí na tlačítko před samotným zpracováním dat.

**Kontrola prázdného jména:**
```csharp
if (string.IsNullOrWhiteSpace(name_textBox.Text))
{
    MessageBox.Show("Zadej jméno!");
    return; // Ukončí metodu
}
```

**Kontrola čísla (např. věk):**
```csharp
int vek;
if (!int.TryParse(vek_textbox.Text, out vek))
{
    MessageBox.Show("Zadej číslo!");
    return;
}
```

## Validace položky (při opuštění prvku)
Používá se událost **`Validating`**. Ta umožní uživateli opustit prvek, jen pokud jsou data správně.

![](/Praktická/imgs/Q12/image45.png)

```csharp
private void name_textBox_Validating(object sender, CancelEventArgs e)
{
    if (string.IsNullOrWhiteSpace(name_textBox.Text))
    {
        e.Cancel = true; // Zamezí opuštění TextBoxu
        MessageBox.Show("Musíš vyplnit jméno!");
    }
}
```

# Kontejnerové komponenty (ListBox, ComboBox)

Slouží k uchovávání a výběru více položek.

## Přidávání položek
Můžeme přidávat přímo v kódu (např. při `Form_Load`):
```csharp
comboBox1.Items.Add("Položka 1");
listBox1.Items.Add("Položka A");
```

## Získávání vybrané položky
- **SelectedItem:** Vrací samotnou hodnotu (např. text).
- **SelectedIndex:** Vrací pořadí položky (indexováno od 0). Pokud není nic vybráno, vrací -1.

**Příklad pro ListBox:**
```csharp
if (listBox1.SelectedIndex != -1)
{
    string vybrano = listBox1.SelectedItem.ToString();
    lblInfo.Text = $"Vybráno: {vybrano} na indexu {listBox1.SelectedIndex}";
}
```

```csharp
private void listBox1_SelectedIndexChanged(object sender, EventArgs e)
{
    int index = listBox1.SelectedIndex;

    if (index != -1)
    {
        label1.Text = "Index: " + index;
    }
    else
    {
        label1.Text = "Nic není vybráno";
    }
}
```
