## HTML

Hyper Text Markup Language

Není to programovací jazyk, ale značkovací jazyk.

|HTML Element|Účel|
|------------|-------------------|
|`<html>`|Hlavní obal celého webového dokumentu.|
|`<head>`|Neviditelné informace (název záložky, meta data, napojení na styly).|
|`<body>`|Veškerý viditelný obsah stránky pro uživatele.|
|`<div>`|Univerzální "krabice" pro blokové seskupování prvků (layout).|
|`<h1>` - `<h6>`|Nadpisy (od nejdůležitějšího `<h1>` po nejmenší `<h6>`).|
|`<p>`|Běžný textový odstavec.|
|`<span>`|Řádkový obal pro kousek textu (např. pro obarvení jednoho slova).|
|`<strong>`|Tučný text (sémantické zdůraznění důležitosti).|
|`<em>`|Text kurzívou (důraz na výslovnost/význam).|
|`<a>`|Klikací odkaz na jinou stránku nebo web.|
|`<img>`|Zobrazení obrázku.|
|`<ul>`|Neřazený seznam (s odrážkami/puntíky).|
|`<ol>`|Řazený seznam (číslovaný).|
|`<li>`|Konkrétní položka uvnitř seznamu (`<ul>` nebo `<ol>`).|
|`<table>`|Hlavní obal pro vytvoření tabulky.|
|`<tr>`|Jeden vodorovný řádek v tabulce (Table Row).|
|`<th>`|Buňka s hlavičkou tabulky (Table Header, text bývá tučně).|
|`<td>`|Standardní buňka s daty v tabulce (Table Data).|
|`<form>`|Hlavní obal formuláře pro odesílání dat.|
|`<input>`|Vstupní políčko (pro text, e-mail, heslo nebo zaškrtávátko).|
|`<button>`|Klikací tlačítko (např. pro odeslání formuláře).|

### Hlavička

---

- Do VS Code se napise jen `html:5` a zobrazi se toto bez stylu a js

``` HTML
<!DOCTYPE html>
<html lang="cs">
<head>
    <meta charset="UTF-8"> <!-- Urční znakové sady -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- view port - viditelna plocha obrazovky -->
    <!-- width=device-with - Prohlížeč nastaví šířku webu na šířku displaye -->
    <!-- initial-scale=1.0 - Zobrazí se web v měřítku jedna -->
    <title>Title</title> <!-- Název stránky co je na záložce nahoře -->
    
    <link rel="stylesheet" href="style.css"> <!-- Napojení na styly -->
</head>
<body>

    <h1>Tělo stránky</h1>

    <script src="script.js"></script> <!-- Napojení na JavaScript -->
</body>
</html>
```

### List (seznamy)

---

Dělá se spíše kvůli prohlížeči aby to bylo více košér ohledně SEO a zjednodušení formátování.

#### Neřazený
  
``` HTML
<ul> <!-- unordered list -->
    <li>Položka</li>
    <li>Položka</li>
    <li>Položka</li>
</ul>
```

#### Řazený

``` HTML
<ol> <!-- ordered list -->
    <li>První položka</li>
    <li>Druhá položka</li>
    <li>třetí položka</li>
</ol>
```

``` HTML
        </tr>
    </thead>
    <tbody> <!-- tělo tabulky  -->
        <tr> <!-- 1. řádek -->

            <td>Praha</td>
            <td>28</td>

        <tr><!-- 2. řádek -->
            <td>Eva Malá</td>
            <td>Brno</td>

        </tr>
    </tbody>
</table>
```

### Form (Formulář)

- `select` - seznam ze kterého se vybere jedna možnost

- `fieldset` - seskupení inputů - logicky pro rozdělení dat i vizualně
- `label` - popis inputu
- `legend` - popis fieldsetu

## CSS

- Dává vlastnosti HTML - přiřazuje barvu, velikosti, rámečky, fonty etc.
- Ukládá se do separátního souboru, klidně se jeden CSS soubor napojuje na více HTML souborů
- funguje díky přiřazování na **class** nebo **id** většinou více vlastností

### Selektory

- to jakým způsobem se označují elementy
  - id
  - class
  - tag
  - combinace


``` css
.class {
  vlastnost: hodnota;
  vlastnost1: hodnota1;
}

#id {
  vlastnost: hodnota;
  vlastnost1: hodnota1;
}

tag(body, div, p) {
  vlastnost: hodnota;
  vlastnost1: hodnota1;
}
```

#### Combinace

- dá dohromady více elementů například potřebujeme všechny elementy `p` a elementy s určitou classou upravit
- dokáže i vybírat všechny podřízené prvky či vybírat následující prvek

### Jednotky

- absolutní 
- relativní
 

- **Absolutní** - dávají jeden rozměr na element, hodí se na zkoušení, učení 
  - px
  - mm

- **Relativní** - velikost přizpůsobují vzhledem k něčemu paktičtější kvůli responzivitě
  - % - velikost nadřazeného prvku
  - vh/wh - výška/šířka okna
  - em/rem - velikost písma

### Atributy (vlastnosti)

vlastnoti které dáváme objektům které jsme si určili podle selektorů

- Písmo 
  - `color:` Barva textu.
  - `font-size:` Velikost písma.
  - `font-family:` Typ písma (font).
  - `font-weight:` Tloušťka písma (např. tučné).
  - `text-align:` Zarovnání textu (vlevo, vpravo, na střed, do bloku).
- Box model (rozměry, kraje)
  - `width:` Šířka.
  - `height:` Výška.
  - `margin:` Vnější mezera (odsazení prvku od ostatních).
  - `padding:` Vnitřní výplň (mezera mezi okrajem prvku a textem uvnitř).
  - `border:` Rámeček kolem prvku
- Pozadí a vzhled
  - `background-color:` Barva pozadí.
  - `background-image:` Obrazek pozadí.
  - `border-radius:` Zakulacení rohů.
- Rozvržení a pozicování
  - `display:` hování prvku (`block`, `inline`, `flex`, `grid`)
  - `position:` Způsob umístění (`relative`, `absolute`, `fixed`, `sticky`)

### Flex

---

- Flexbox zapínáš pomocí display: flex; na rodičovském obalu. Tím se ti odemknou mocné nástroje: flex-direction řídí směr (řádek/sloupec), justify-content a align-items řeší zarovnání a mezery, a flex-wrap zařídí, aby prvky nepřetekly přes okraj, ale poslušně se zalamovaly. Jednotlivým dětem navíc můžeš svévolně měnit pořadí pomocí order. Základ responzivity a modetních webů

### Pseudo třídy, pseudo elementy

---

- Dovolují ti upravovat věci bez toho, abys musel do HTML přidávat další zbytečné značky nebo třídy.

  - **Pseudo-třídy** (1 dvojtečka :): Reagují na stav prvku (např. když na něj najedeš myší) nebo na jeho pozici (např. každý sudý řádek v tabulce).

  - **Pseudo-elementy** (2 dvojtečky ::): Dovolují ti nastylovat jen určitou část prvku (např. jen první písmeno) nebo před/za prvek vložit úplně nový obsah, který v HTML vůbec není.

### Document Object Model (DOM)

- umožňuje komunikaci mezi Js a HTML aby se Js projevil
-  Když prohlížeč přečte tvůj HTML kód, vytvoří si z něj v paměti živou 3D mapu. Této mapě se říká DOM. Není to už jen text, ale soubor objektů.

<div style="display: flex; gap: 20px; align-items: flex-start; margin-bottom: 40px;">
  <div style="flex: 1;">

  ```html
  <html>
    <body>
      <h1>Ahoj</h1>
      <p>Text</p>
    </body>
  </html>
  ```

  </div>
  <div style="flex: 1;">
    <div style="background: #1b3a1d; padding: 10px; border: 1px solid #2e7d32; border-radius: 5px; color: #e0e0e0;">
      Prohlížeč si to poskládá jako <strong style="color: #a5d6a7;">rodokmen (strom)</strong> obrácený vzhůru nohama.<br>
      <code>html</code> je rodič, <code>body</code> je dítě a <code>h1</code> s <code>p</code> jsou sourozenci.
    </div>
  </div>
</div>

<div style="display: flex; gap: 20px; align-items: flex-start;">
  <div style="flex: 1;">

  ```javascript

  ```

  </div>
  <div style="flex: 1;">
    <div style="background: #102a43; padding: 10px; border: 1px solid #1976d2; border-radius: 5px; color: #e0e0e0;">

    </div>
  </div>
</div>

- sleduje aktivity uživatele na určitém prvku definovaným DOMem, díky tomu může reagovat (najetí na tlačítka, click, zmáčknutá klávesa etc.)

#### AJAX - REST API

##### Princip a význam async komunikace

AJAX (Asynchronous JavaScript and XML) technologie používaná ke komunikaci se serverem. Dnes je použínán JSON místo XML.
Hlavní je plynlost - to že může uživatel pracovat a komunikace se řeší na pozadí za pochodu a není potřeba refreshovat stránku.

##### Asynchronní vs synchronní komunikace

- **Synchronní** - čeká než přijde odpověd serveru, prohlížeč "zamrzne"
  - např. přihlášení, odesílání formu
- **Asynchronní** - **ne**čeká než přijde odpověd serveru, prohlížeč jede bez zastavení a uživatel nic nepozná
  - např. donačítání položek

##### fetch a async/await

fetch() je moderní funkce v JavaScriptu pro síťové požadavky. Vrací tzv. Promise (slib). Aby byl kód čitelnější a vypadal jako synchronní, používají se klíčová slova async (pro označení asynchronní funkce) a await (čekání na dokončení slibu).

1. Získání dat **GET**

```javascript
async function ziskejData() {
  const response = await fetch('https://api.priklad.cz/data'); // Výchozí je GET
  const data = await response.json(); // Převod odpovědi na JS objekt
  console.log(data);
}
```

1. Odeslání dat **POST**

```JavaScript

async function odesliData(novaData) {
  const response = await fetch('https://api.priklad.cz/ulozit', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json' // Informujeme server, že posíláme JSON
    },
    body: JSON.stringify(novaData) // Převod JS objektu na textový JSON
  });
}
```

Použití

- načítání dat bez reloadu stránky
- komunikace s REST API (nejpoužívanější typ, další jsou: SOAP, GraphQL)
- formuláře (odesílání, ukládání)
- ukládání a načítání údajů
  
##### Ošetření chyb

- Kód pro síťový požadavek balíme do bloku try. Pokud spojení selže (např. výpadek internetu), kód skočí do bloku catch.

```js
async function stahniData() {
  try {
    // 1. Zkusíme stáhnout data ze serveru
    const odpoved = await fetch('https://api.priklad.cz/data');

    // 2. Zkontrolujeme, zda odkaz opravdu existuje (není to např. chyba 404)
    if (!odpoved.ok) {
      throw new Error("Data se nepodařilo najít.");
    }

    // 3. Pokud je vše v pořádku, převedeme data a vypíšeme je
    const data = await odpoved.json();
    console.log(data);

  } catch (chyba) {
    // 4. Sem kód přeskočí, pokud vypadne internet nebo selže bod 2
    alert("Chyba: " + chyba.message);
  }
}
```
